# 🚀 Project Management Dashboard

A modern and responsive **Project Management Dashboard** built using **HTML, CSS, JavaScript, and Supabase**. The application enables teams to manage projects efficiently through secure authentication, role-based access control, project tracking, analytics, and an intuitive user interface.

---

## 📌 Project Overview

This project simulates a real-world project management system where users can securely log in, manage projects, track activities, monitor goals, and visualize project statistics through an interactive dashboard.

The application supports **Admin** and **User** roles, ensuring that each user has access only to the modules they are authorized to view.

# 🚀 Installation

Clone the repository

```bash
git clone https://github.com/YOUR_USERNAME/Project-Management-Dashboard.git
```

Go into the project directory

```bash
cd Project-Management-Dashboard
```

Configure your Supabase project by updating:

```
supabase-config.js
```

Run the project using Live Server or your preferred local server.
